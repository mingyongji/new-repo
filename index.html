能力方向

不是"接了 API 调通"，而是把一条链路做稳：检索质量、工具可靠性、成本与延迟、上线后的可验证性。

🔍 RAG 与知识库

中文父子块递归切分解决长流程文档断章取义；按业务域拆多集合减少跨域串味；BM25 精确匹配叠加向量召回，再经 reranker 精排，把知识问答准确率从 76% 拉到 92%。

🧩 Agent 与多步编排

把中台查询与操作能力封装成 12 类原子工具，用 LangGraph 按「意图理解 → 工具规划 → 分步执行 → 结果校验 → 汇总回复」编排，支持分支判断与异常重试，多步调用准确率 90% 以上。

⚡ 路由与成本优化

「精确匹配 → 知识检索 → 工具执行」三层路由让高频问题 30ms 命中、不进大模型；模型侧用随机森林基线 + FastText 初筛 + BERT 精判，只让歧义样本进入大模型。

🛡 工程与稳定性

FastAPI + SSE 流式输出；统一超时、重试与熔断降级避免请求悬挂；90 秒任务看门狗兜底；规则与数据 24 小时增量同步，无需重建索引。
